## Estados de validación
- `ficha_youtube_indexada`: título y descripción visibles en un resultado indexado de YouTube, **no constituye visionado**.
- `video_incrustado_en_prensa`: URL encontrada como incrustación en un artículo, **no garantiza reproducción actual**.
- `pendiente_de_visionado_directo`: no hay una observación audiovisual comprobada.
- `video_revisado`: solo se marca así tras visionar la escena y documentar marca de tiempo.

## Protocolo para añadir un análisis real
1. Abrir el video; registrar fecha del acceso, canal e intervalo exacto (ej. 01:10–02:05).
2. Anotar una **sinopsis propia**, no transcribir diálogos completos.
3. Descomponer contexto → expectativa → giro → remate → reacción del público.
4. Registrar cómo intervienen tono, gestos y pausas.
5. Extraer una técnica general y **crear una escena original** que no copie el material.
6. Guardar la observación con [plantilla de ficha](../plantillas/ficha-video.md).
